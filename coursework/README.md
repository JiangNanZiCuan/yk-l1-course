# 内核猜数小游戏

这是本次课程设计独立编写的内核模块和 C 应用程序，不使用设备中原有的 hello 模块。

内核随机选择 1 至 100 的数字，通过 `/proc/guess_game` 接收猜测并返回反馈。`higher` 表示需要猜得更大，`lower` 表示需要猜得更小，`won` 表示猜中。秘密数字不会由读取接口泄露。内核将开局和每次有效猜测写入系统日志。

应用读取真实内核反馈，将过程同时显示在控制台并写入 `/tmp/guess_result.txt`。默认自动使用二分查找，最多七次猜中。开机时固件自动加载模块并演示一局。

## 使用

网页控制台执行的命令均会立即返回，不需要打开持续运行的交互程序。

```sh
guess_client --auto
cat /tmp/guess_result.txt
```

手动猜数时，先执行一次 `guess_client --new`，然后多次执行 `guess_client --guess 50`（替换数字）。`guess_client --status` 查看反馈。开始新局或自动演示会覆盖结果文件；手动猜测和状态查询追加到当前结果文件。

```sh
guess_client --new
guess_client --guess 50
guess_client --status
```

系统日志筛选：`dmesg | grep guess_game`。内核接口为管理员可读写；所有玩家共享同一局，请一次只使用一个客户端。自动客户端发现状态被其他玩家改变时会退出。

结果在 `/tmp` 中，重启后重新生成，不反复写入闪存。路由器时间未校准时，报告中的日期可能是默认日期；尝试次数和反馈不依赖系统时钟。

## 源码与验证范围

- `guess_game.c`：Linux 3.4 procfs 接口、随机数、互斥锁和日志。
- `guess_logic.h`：数字比较和回合状态。
- `guess_client.c`：自动与手动客户端、结果文件。
- `integrate.py`：加入固定版本 Padavan 构建，不修改设备。
- `test_logic.c`：覆盖全部 100 个答案、最多七次求解、无效范围、已结束回合和重置。

云端构建会检查 MIPS 程序、内核模块和启动脚本是否进入固件。云端逻辑测试和编译通过不等于实体路由器已运行验证；刷机前仍须确认备份与恢复条件。
